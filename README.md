# 霓虹方块

一个支持电脑和手机操作的网页版俄罗斯方块小游戏。无需安装依赖，直接打开 `index.html` 即可运行。

## 游戏功能

- 完整的方块移动、旋转、碰撞、落地与消行规则
- 分数、消除行数、等级和本地最高分记录
- 下一个方块预览与幽灵落点提示
- 键盘操作、手机触控按钮和棋盘滑动操作
- 暂停、重新开始、音效开关与页面切出自动暂停
- 自适应电脑和手机屏幕的霓虹像素界面

## 操作方式

### 电脑

- `←` / `→`：左右移动
- `↑`：旋转
- `↓`：加速下降
- `空格`：直接落下
- `P` 或 `Esc`：暂停/继续
- `R`：重新开始

### 手机

使用棋盘下方的触控按钮，也可以直接在棋盘上操作：轻点旋转、左右滑动移动、向下长滑直接落下。

## 本地运行

下载项目后双击 `index.html`，或者在项目目录中启动任意静态文件服务器。

## GitHub Pages 发布

代码合并到 `main` 分支后，进入仓库的 **Settings → Pages**，在 **Branch** 中选择 `main` 和 `/ (root)`，保存后即可获得在线游戏地址。

## 技术说明

项目使用原生 HTML、CSS、JavaScript 和 Canvas 开发，不依赖第三方框架。
